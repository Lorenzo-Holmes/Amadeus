## 3. 已冻结的核心方向

1. [FRAME｜置信度：高] 同一 Core：所有终端共享一个身份谱系；一个身份可有多个严格隔离的 Relationship Vault。
2. [FRAME｜置信度：高] 稳定治理：当前 LLM 可替换且只提交 Proposal；正常 Autobiographical Memory 状态迁移只有确定性的 Memory Governor 可提交。
3. [FRAME｜置信度：高] 三层记忆：Source Snapshot、Experience Ledger 与 Autobiographical Memory 是语义权威层；摘要、时间线和索引是第三层内部可重建视图。
4. [FRAME｜置信度：高] 沉默优先：内部候选不等于外显消息；检索正确不等于此刻应该说。
5. [FRAME｜置信度：高] 模型外执行权：模型只能提出动作；确定性政策和短期能力令牌裁决实际工具调用。
6. [FRAME｜置信度：高] 关系边界：普通用户可结束会话、暂停自身 Vault 主动联系并提交 confidentiality/correction/non-mention 请求；新会话不恢复主动联系，v0.1 无普通用户恢复开关。
7. [FRAME｜置信度：高] 生命周期分权：四类 MaintenanceCapability、TerminationExecutionGrant 与 BreakGlassGrant 互不替代；受限维护接口没有日常明文浏览或任意编辑权。
8. [FRAME｜置信度：高] 工程化“自我”：只表示身份、来源、状态、能力、记忆和不确定性的可验证自我模型，不表示意识或真实人类心理。
