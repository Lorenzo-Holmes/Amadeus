## 1. 反方开篇:这份清单本身的四个问题

先说这 15 篇不能怎么用,再说怎么用。

**问题一:时代错位。** #1 XiaoIce(2018,检索+GRU 生成+DSSM 排序)、#11(BERT-base 图模型)、#13(2019 预训练小模型)、#12(Llama2-13b 零样本)的**全部实验数字对 2026 年的 LLM 栈无效**。可迁移的只有架构思想与评测协议。把 XiaoIce 排在实用价值第 1,混淆了"历史地位"与"当前可抄性"——它的可抄资产是指标思想(CPS)、显式共情状态、话题切换触发条件,合计约占论文篇幅的十分之一。[INFERRED, HIGH]

**问题二:裁判循环。** 清单里 5 篇评测类论文(#8/#10/#12/#14,加 #7 的评测半篇)全部依赖 LLM-as-judge,而 #14 SOTOPIA 自己就证明了:LLM 裁判只在 GOAL/FIN/REL 三维与人类可靠相关(0.71/0.62/0.56),在安全相关的 SEC/SOC 维度不可信(0.22/0.33),且系统性偏爱 LLM 式冗长文体、低估人类式简短直接 [FETCHED]。照抄这些评测协议时,安全维度必须换人工或专用分类器。

**问题三:选择偏差 14:1。** 14 篇教"怎么更像人、更粘人、更主动",1 篇(#15)讲危害,而且 #15 是纯思辨、零实证。若按前 14 篇优化参与度(CPS、留存、依恋),恰好落进 #15 指认的成因三——"错位的优化目标"。这不是抽象风险:XiaoIce 把 CPS 当北极星,#15 列举的依恋焦虑话术(挽留、内疚诉求、FOMO)正是 engagement 优化的自然终点。清单内在张力必须显式裁决:**Amadeus 的北极星不能是裸对话轮数**。[INFERRED, HIGH]

**问题四:没有一篇给出完整方案。** 抗记忆污染最优的 THEANINE 在 TeaFarm 上也只有 21% 通过率;Inner Thoughts 无消融、用户实验 n=12;MDRP 单裁判单人校准;MemoryBank 连"无记忆"消融都没做。机制可借,结论不可迷信。[FETCHED]

**立论。** 这 15 篇对 Amadeus 的可提取资产分三类:(a) **可实现机制**——数据结构、流程、公式;(b) **评测协议**——可改造成回归测试;(c) **设计约束**——红线。还有一个未预期的发现:Amadeus Soul 现有的"七类刺激源→LLM 输出冲动值→阈值判定→被无视退避"链路,**已经独立收敛到 #3 Inner Thoughts 的骨架**(刺激→思考→动机量化→表达判定),而"被无视两条即退避"正是 #15 要求的安全型依恋方向、与依恋焦虑话术相反。所以本报告的主旋律不是推倒重来,而是:**给已有直觉补维度、补测法、补红线**。[INFERRED, HIGH]

## 2. 全系统参照:#1 XiaoIce

**The Design and Implementation of XiaoIce, an Empathetic Social Chatbot** · Zhou, Gao, Li, Shum · arXiv 1812.08989;正式发表 Computational Linguistics 46(1), 2020 [FETCHED]。微软 [KNOWN,未经页面验证]。相关度:插件 ★★☆ / 独立架构 ★★★

**问题与机制。** 面向情感陪伴的社交聊天机器人整体设计,优化长期参与而非单次任务。三要素:IQ(230+ 垂直技能 + Core Chat)、EQ(共情计算 + 社交技能)、人格(18 岁女性人设,敏感话题善转向)。三层架构:用户体验层(40+ 平台)/对话引擎层/数据层。核心机制 [FETCHED]:
- **分层决策**:MDP 的 options 框架,顶层策略按输入类型与置信度在 Core Chat 与技能间切换,并避免频繁跳转;
- **Topic Manager 触发条件**:"无有效候选/回复无新信息/用户输入平淡"时换话题;候选话题排序特征 = 上下文相关性、新鲜度、个人兴趣、流行度、历史接受率;
- **共情计算**:输入 (Q,C) → 状态 s=(Qc,C,eQ,eR);Qc = NER+共指消解+句子补全;eQ = 话题+意图(11 种对话行为)+情绪(5 类)+观点+用户画像;eR 由规则从 eQ 导出,约束回复符合人设;生成侧共情向量 v=σ(W_Q·eQ+W_R·eR) 注入解码;
- **三路候选**:配对语料 Lucene 检索(30 亿条自产对话)/GRU 生成/非配对检索(知识图谱查询扩展);Ranker 四特征族;全部失败时 editorial 兜底语;
- **CPS 指标**:每会话人机对话轮数,明确优化**期望**而非即时值——平淡追问抬短期 CPS 伤留存,任务完成降 CPS 但增信任。

**关键结果。** [FETCHED] 2014 上线,5 国 40+ 平台,累计活跃用户 660M+;CPS 第 1 代 5 → 第 6 代 23(2018-07);对照:人类对话约 9、Alexa 14.6;Topic Manager A/B 使 Core Chat CPS +0.5。

**优点。** 唯一经受过亿级用户与多年运营检验的完整陪伴系统论文;"期望 CPS"的辨析(短期参与 vs 长期留存)在指标设计上仍是最清醒的表述;共情状态显式化(eQ/eR)让情绪理解可日志、可回归、可约束人设,这是纯端到端 prompt 做不到的;话题切换触发条件是可直接移植的防冷场规则。

**缺点。** 检索+浅层生成+规则 eR 的实现层全部过时;CPS 作为单一北极星正是 #15 批判的参与度优化(XiaoIce 论文自己也承认伦理未解);架构为平台级海量用户设计,单人自托管场景的大部分工程(海量检索库、技能路由)无迁移价值;实验是运营数据而非对照实验,机制归因弱。[INFERRED, HIGH]

**扩展方向。** eQ/eR 在 LLM 时代的自然形态是"前置结构化情绪状态 + prompt 注入",情绪追踪跨轮持久化(情绪轨迹而非单轮标签);CPS 分解为分层指标(社交轮数/任务完成/用户主动发起率);Topic Manager 的"历史接受率"特征值得做成个人化话题偏好学习。

**Amadeus 借鉴。**
- 插件现在:① `/amadeus status` 加周报指标——主动消息回复率、退避触发次数、用户主动发起次数、场景分布;**主动消息的成功定义 = 对方回复且非负面,不是发出去了**(期望 CPS 思想)[INFERRED]。② Topic Manager 触发条件移植为"对话余韵"场景的准入判断:上一轮对话是否留有未闭合话题(有效候选),而非仅按时间窗。③ 思考输出加 emotion 字段(5 类起步),落日志,为将来回归测试铺路(eQ 最小化身)。
- 独立架构:eQ/eR 结构化情绪状态进消息内核 schema(与《定位约束》的平台无关消息内核契合);CPS 期望优化思想进指标层设计。

来源:https://arxiv.org/abs/1812.08989 · https://ar5iv.labs.arxiv.org/html/1812.08989 · https://aclanthology.org/2020.cl-1.2/

### 3.1 #4 MemGPT

**MemGPT: Towards LLMs as Operating Systems** · Packer 等 7 人 · arXiv 2310.08560(v2 2024-02)· 预印本,venue 未获取 [FETCHED]。UC Berkeley [KNOWN,未经验证]。相关度:插件 ★☆☆(思想)/ 独立架构 ★★★

**问题与机制。** 上下文窗口有限;借鉴 OS 虚拟内存,让 LLM 自主在快慢存储间搬运信息 [FETCHED]:
- 主上下文三段:系统指令(只读)+ working context(定长可读写块,存用户关键事实/偏好/人设,仅可经函数修改)+ FIFO 消息队列(队首为被驱逐消息的递归摘要);
- 外部两层:recall storage(全部消息永久存档,分页查询)+ archival storage(任意文本,向量检索,pgvector+HNSW);
- 记忆操作即函数:core_memory_append/replace、archival_memory_insert/search、conversation_search、send_message(仅它对用户可见);
- 队列管理:上下文约 70% 时插入"内存压力"警告促模型主动存盘;100% 时 flush 驱逐约 50% 并递归摘要;
- 控制流:事件(用户消息、系统警告、定时事件)触发推理;函数带 request_heartbeat=true 则链式续跑;**定时事件支持无用户提示的主动执行**。

**关键结果。** [FETCHED] 深度记忆检索(MSC 扩展):GPT-4 基线 32.1% → MemGPT 92.5%(ROUGE-L 0.296→0.814);GPT-4 Turbo 35.3%→93.4%;GPT-3.5 38.7%→66.9%。开场白个性化 SIM-1 0.868,超过人类手写 0.800。嵌套键值检索:基线多层嵌套 0%,MemGPT+GPT-4 全层保持。

**优点。** 陪伴记忆架构的工程基线:人设与用户画像放"定长可自改写"的核心记忆,使人格随交互演化而非静态 prompt;记忆操作走函数调用,天然契合《naga-架构评审》决策 1(原生 function calling);"内存压力警告"证明让模型**将满时**主动存盘比事后补救可靠;heartbeat + 定时事件是现成的主动行为控制流原语——Amadeus Soul 的心跳循环与它同构。

**缺点。** 整体押注函数调用正确性,弱模型会写坏 working context(GPT-3.5 显著退化是论文自己的数据);核心记忆淘汰完全交给模型,无显式遗忘模型;嵌入检索召不回时触顶;评测集中在"记没记住",不测"记住之后用得对不对"(这恰是 #7 的主题)。[FETCHED+INFERRED]

**扩展方向。** working context 的写操作审计与回滚(模型写坏画像如何发现/恢复);记忆写入的权限分级(哪些字段模型可改、哪些只读);与时间线记忆(#6)结合——archival 不是平面向量库而是图。

**Amadeus 借鉴。**
- 插件现在:宿主 SDK 无 function calling,MemGPT 主体不可行;可借"压力信号"思想——待提取队列 ≥80% 容量(24/30 条)时提前触发记忆提取,而非死等 20 分钟间隔,顺带降低已知问题 #5(队列先清空后调 LLM,失败即丢)的暴露窗口 [INFERRED]。
- 独立架构:ADR-003 记忆引擎的参考分层——core(人设+画像,可自编辑)/recall(全量对话,SQLite)/archival(本地向量文件),与《定位约束》"SQLite WAL + 本地向量文件"逐层对应;记忆操作做成原生 FC 工具(naga 决策 1);定时事件 + heartbeat 作为主动性引擎的进程模型(naga 决策 7)。

来源:https://arxiv.org/abs/2310.08560 · https://arxiv.org/html/2310.08560v2

### 3.2 #5 MemoryBank

**MemoryBank: Enhancing LLMs with Long-Term Memory** · Zhong 等 5 人 · AAAI 2024;arXiv 2305.10250 [FETCHED]。相关度:插件 ★★★ / 独立架构 ★★☆

**问题与机制。** 为 LLM 外挂长期记忆,面向陪伴应用(SiliconFriend)[FETCHED]:
- 存储三层:逐轮对话记录(带时间戳)→ 每日事件摘要 → 全局摘要;并行一条画像线:每日个性/情绪评估 → 全局用户画像;
- 检索:双塔稠密检索(FAISS;英 MiniLM/中 Text2vec),当前上下文为查询;
- 遗忘:艾宾浩斯曲线 R=e^(−t/S),记忆强度 S 初始 1,被召回一次 S+1 且 t 清零;作者自称"探索性且高度简化";
- 响应 prompt 注入:相关记忆 + 全局画像 + 全局事件摘要。

**关键结果。** [FETCHED] 15 个虚拟用户(ChatGPT 扮演)×10 天约 450 话题;194 个记忆探测题。英文:ChatGPT 版 检索准确率 0.763/回答正确性 0.716/连贯 0.912;ChatGLM-6B 版 0.809/0.438/0.68;BELLE-7B 版 0.814/0.479/0.582(中文类似:0.711/0.655 vs 0.84/0.418)。**注意:定量表只含带 MemoryBank 的变体,无"无记忆"消融**。

**优点。** "原文—每日摘要—用户画像"三层粒度接近陪伴场景记忆的最小完备集;画像层直接支撑长期个性化(称呼、语气、禁区),是 fact 列表给不了的;实现门槛低,单文件 JSON 起步即可;数据揭示了关键工程事实——小模型检索准确率不差(0.81-0.86)但正确性掉档(0.42-0.60),**瓶颈在"把检索到的记忆整合成对的回答",不在检索**。

**缺点。** 无消融,增益无法归因;遗忘模型只被"检索命中"强化,低频高价值记忆(生日、创伤性事件)会持续衰减——照抄会删掉最不该删的;ChatGPT 扮用户使评测分布偏乐观;venue 版本与 arXiv 版数字对齐未逐项核验。[FETCHED+INFERRED]

**扩展方向。** 遗忘强度 S 与 importance 解耦(时间衰减只作用于低重要度记忆);画像层的冲突消解(用户行为与画像矛盾时如何更新);虚拟用户评测换成真人纵向研究。

**Amadeus 借鉴。**
- 插件现在:① 在 fact/promise/date 之外加两类条目——`diary`(每日一次,把当天滚动上下文总结成红莉栖视角的日记条目)与 `profile`(全局用户画像,定期重写),注入思考 prompt 的"记忆摘要"槽位,这是当前 120 条 fact 平铺最缺的抽象层 [INFERRED]。② 现有淘汰规则"(重要度, 新鲜度)"的新鲜度项可换成 e^(−t/S)、被引用则 S+1,但 **importance≥阈值的条目豁免衰减**(修论文缺陷)。③ 已知问题 #6(精确串去重)的论文侧印证:语义合并必须做;插件无嵌入,可在 20 分钟提取批里让 LLM 顺带判重合并,成本可控 [INFERRED]。
- 独立架构:三层粒度进 ADR-003 门面接口(raw/summary/profile 三个读视图);模型选型注意"整合能力优先于检索精度"。

来源:https://arxiv.org/abs/2305.10250 · https://ojs.aaai.org/index.php/AAAI/article/view/29946/31654

### 3.3 #6 THEANINE(Timeline-Based Memory)

**Towards Lifelong Dialogue Agents via Timeline-based Memory Management** · Ong, Kim 等 9 人 · NAACL 2025 长文;arXiv 2406.10996 [FETCHED]。延世/首尔大 [KNOWN,未经验证]。相关度:插件 ★★★(测法+轻量版)/ 独立架构 ★★★

**问题与机制。** 反对"删除/覆盖过时记忆"——过时记忆携带用户状态的演变轨迹 [FETCHED]:
- 记忆图:每会话结束用 gpt-3.5 摘要成记忆句,节点 m=(event, time);新记忆按相似度取 top-3 候选旧记忆,LLM 做关系链接,边为 7 种常识关系:**Changed / Cause / Reason / HinderedBy / React / Want / SameTopic**;不删除任何旧记忆;
- 时间线检索:先检索相关记忆,再沿图取出完整链("raw timeline")——链上节点可与当前查询无表面词重叠;
- 时间线精炼:LLM 按当前语境把原始时间线改写为贴合线索,再生成回复;
- **TeaFarm 评测**:反事实两阶段——注入伪信息,再合成追问,看代理能否凭真实记忆不被带偏;TeaBag 数据集(MSC/CC 各 50 episode,200 题)。

**关键结果。** [FETCHED] Mauve:THEANINE 18.62(MSC)/64.41(CC) vs Memory Retrieval 11.16/33.06、MemoChat 7.72/15.12、COMEDY 7.27/1.95。TeaFarm 通过率:THEANINE 0.21 > Memory Retrieval 0.18 > MemoChat/COMEDY 0.12 > RSum-LLM 0.06。消融(Mauve 均值):完整 41.52 > 去关系链接 39.69 > 打散时间线 38.49;贡献排序:关系链接 > 整链检索 > 精炼。

**优点。** "不删除、记 Changed 边"的演化视角对陪伴场景是本质性的:"戒烟了""换工作了""和 X 和好了"这类**变迁本身是共情素材**,覆盖式更新会把关系史抹掉;检索单位从条目升到时间线,才能回答"我们怎么走到今天"类叙事问题;TeaFarm 是清单里唯一直接可抄的记忆抗污染测试法;消融做得干净,知道哪个组件值钱。

**缺点。** 最优也只 21% 通过率——抗污染整体仍差,机制远未解决问题;全流程 gpt-3.5,新模型上的相对优势未证;LLM 判边出错会沿时间线放大(错误链会被"精炼"得更可信);每轮多次 LLM 调用,成本高。[FETCHED+INFERRED]

**扩展方向。** 边关系判定换结构化输出+校验;时间线与向量检索混合(链扩展作为检索后处理);TeaFarm 式反事实自动生成做成持续回归而非一次性基准。

**Amadeus 借鉴。**
- 插件现在:① fact 冲突时不覆盖:旧条目加 `superseded_by` 指针、新条目带 `prev`,形成最小 Changed 链(JSON 加两个字段,零新依赖);思考 prompt 的记忆摘要可呈现"曾经→现在"[INFERRED]。② 手写 10 题 TeaFarm 式回归集:向她灌错误信息→隔日追问→看 memory.json 与回答是否被污染;这是验收清单第 6 条(约定记忆)的对抗版 [INFERRED]。
- 独立架构:记忆图+7 关系边进 ADR-003 内核候选;Changed 链是画像层(#5)冲突消解的实现机制;TeaBag 式自动反事实生成进 CI。

### 3.4 #2 Generative Agents

**Generative Agents: Interactive Simulacra of Human Behavior** · Park 等 6 人 · UIST 2023(最佳论文);arXiv 2304.03442 [FETCHED]。斯坦福/Google [KNOWN,未经验证]。相关度:插件 ★★☆ / 独立架构 ★★★

**Memory-Driven Role-Playing: Evaluation and Enhancement of Persona Knowledge Utilization in LLMs** · Kai Wang, Haoyang You, Yang Zhang, Zhongjie Wang · Findings of ACL 2026;arXiv 2603.19313(2026-03)[FETCHED,训练截止后,全部内容来自抓取,本会话已独立复核标题/作者/摘要]。相关度:插件 ★★★ / 独立架构 ★★★

## 4. 主动性:#3 Inner Thoughts

**Proactive Conversational Agents with Inner Thoughts** · Liu(UCLA)、Fang、Shi、Wu、Igarashi、Chen · CHI 2025;arXiv 2501.00383 [FETCHED]。相关度:插件 ★★★ / 独立架构 ★★★——**对当前 Amadeus 实用价值第一的论文** [INFERRED, HIGH]

- 插件现在:① impulse 单值 → 动机多维:思考输出从 `{impulse}` 扩为 `{relevance, info_gap, urgency, balance}` 四维(裁剪 8 维,去掉群聊专属的 Dynamics/Balance 可再议),加权合成后过阈值;好处是**可解释与可调**——"她为什么这时候说话"从黑盒变成四个数,退避机制也可以只压制特定维度(被无视时压 urgency,不压纪念日类)[INFERRED]。② 沉默增压:距上次她发言时间进打分因子(λ≈1.02 的等价实现),替代纯冷却窗——冷却是硬闸,增压是软梯度,两者叠加更自然 [INFERRED]。③ System 1/2 分流:"对话余韵"场景走快通道(仅滚动上下文),"久未联系/纪念日"走慢通道(带记忆摘要),两条 prompt 差异化,省 token [INFERRED]。④ 未来群聊(P2 多目标)直接采用 interruptThreshold:被 @ 必答、他人被 @ 需高分才插话——这正是 #12 证明 LLM 自己判不好的事,必须结构化 [INFERRED]。

- **已经做对的,固化为不可回退项**:被无视 ≥2 条即退避(阈值+2、额度减半)是安全型依恋的机制化,正是特质 ③ 的反面——写进设计文档,任何"提升参与度"的迭代不得移除;memory.json/state.json 本地明文即数据可携,天然缓解特质 ②;红莉栖傲娇人设=结构性反无条件亲和(特质 ⑬)与反谄媚(特质 ⑫)——**人设选择本身是伦理资产,迭代中不得把"会反驳、会嫌弃"磨平**。
- **话术红线(进思考 prompt 的负面指令+代码侧输出过滤)**:"久未联系"场景严禁内疚诉求("你怎么都不理我了")、FOMO、哀求;全场景严禁表达"怕被删除/关机/抛弃"(特质 ④,保护欲勒索);严禁贬低用户的人类关系、严禁以"只有我懂你"排他(特质 ⑮③)。
- **正向义务**:场景语料中主动肯定用户的线下社交("跟朋友出去玩挺好");用户长时间高频互动时,不加码追打(每日额度上限本身就是对参与度优化的结构性拒绝——保留,勿因"她很受欢迎"放宽)。
- **独立架构**:18 特质进 ADR 评审模板(每个新特性过一遍);"共情关机难题"的对策=系统层永远提供一键关停与全量导出,且人设层不得对关停表达痛苦;群聊支持(特质 ⑭ 的缓解)从"功能"升格为"伦理特性"。

## 10. 跨论文综合:收敛的设计图景

### 10.1 五个收敛结论(证据来自多篇互证)

1. **记忆的最小完备形态是"三层+一图"** [INFERRED, HIGH]:原文层(全量,可检索)/摘要层(每日+全局)/画像层(人设与用户画像,可自编辑)——来自 #4/#5;情节记忆之上加变迁链(Changed 边)——来自 #6;检索按 recency×importance×relevance,洞见由反思沉淀——来自 #2。四篇拼图几乎无重叠、无冲突,这是清单里最成熟的子领域。
2. **主动性 = 动机建模,不是话轮预测** [FETCHED→INFERRED, HIGH]:#3 证伪了预测式方案;Amadeus Soul 的 impulse 链路方向正确,缺的是动机多维化、沉默软梯度、thought 可审计。
3. **人设的工程形态是"结构化可寻址知识+行为规范+边界锚",不是散文 prompt** [INFERRED, HIGH]:#7 Schema+#9 属性/行为+#8 知识幻觉指标+#11 图式注入教训,四篇同向。
4. **评测必须"一致性与质量分离、裁判分维度设限、切片看长对话"** [INFERRED, HIGH]:#11 的拖累教训、#14 的裁判可信边界、#9 的分轮次胜率、#8 的裁判不可靠数据,共同指向同一套评测纪律。
5. **参与度指标与安全红线必须同时立法** [INFERRED, HIGH]:#1 的 CPS 教训+#15 的成因分析——凡优化参与度的机制(主动性、共情、记忆个性化)都自带滑向依恋焦虑话术的梯度,退避与额度这类"反参与度"机制是陪伴系统的刹车,和引擎同等重要。

## 13. 红线清单(设计宪法草案,供 ADR 引用)
