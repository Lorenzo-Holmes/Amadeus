# Bounded conversation and state boundary repair

Ordinary conversation with no typed semantic plan previously reached a fixed unsupported-input fallback. An explicitly bound BOUNDED conversation session now retains an otherwise eligible natural answer. Display eligibility grants conversational use only; fact truth, state admission and state commit remain separate decisions.

The adopted P1 contract and exact fourteen-path implementation allowlist are unchanged. Thirteen paths changed: seven runtime files, four direct validation consumers and the two designated new test files. The existing transcript-store interfaces already support the required projections, so that conditional path needed no edit.

## Versioned behavior

- Display policy: `BOUNDED_CONVERSATION_1`; record schema: `RAW_DISPLAY_ACCEPTED_IDENTITY_2`; formal binding: `FORMAL_BOUNDED_BINDING_1`.
- State policy remains `admission-46.2`. Strict claims retain `TRUSTED_SEMANTIC_ACCEPTANCE_1`, its finite catalog, host validator, certificates and controlled renderer.
- Session policy, consumer purpose and task role select ordinary display or the strict claim path. Missing/corrupted/source-incompatible bindings fail explicitly. Existing OFF and TRUSTED records retain their versioned meaning.
- Raw provider text, policy acceptance, actual display acknowledgment, optional strict claim proof, admission decisions and commit outcomes retain separate provenance. Display/history/next-turn consumers use acknowledged display bytes.
- A host may certify a finite claim within the same displayed turn without rewriting the surrounding commentary or awarding event authority. The scoped proof does not certify the whole answer.
- Observed speech carries `described_events_proven=false` and `content_is_event_proof=false`. Existing allowed effects, evidence seals, receipt checks, admission rules and reducers are unchanged.

## Consumer and review integration

The formal driver binds the new source, policy, schema, contract, dataset, rubric and consumers. Ordinary display does not request a typed envelope. Evaluation retains separate raw, displayed, accepted and state views, while blind projection receives only the approved displayed answer and a separate restricted provenance map.

The evaluator consumes the frozen routing for the same 44 turns and 176 original criteria: Gate A has 176 subchecks and Gate B has 132. Those subchecks do not create a new denominator. Display eligibility or guard blocking never supplies an automatic semantic PASS. State judgments require actual state/trace evidence. Major or Critical blockers prevent acceptance. Original quality thresholds are unchanged.
