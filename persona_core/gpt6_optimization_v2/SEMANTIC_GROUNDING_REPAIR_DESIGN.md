# Source-grounded exclusions and responsibility claims

Candidate exclusions previously checked whether a stated basis appeared in a premise list. That did not connect each exclusion to a candidate domain, an evidence domain or a directed bridge between domains. Actor/phase interpretations also lacked a task-specific scope and support relation. The repair introduces one shared source-binding and support-strength mechanism for both operations.

`semantic_grounding.py` binds each proposed evidence reading to an existing occurrence, exact source span, original quote and full enclosing text. It retains the actual source speaker/authority, proposed modality, temporal state, claim type, task, actor, scope, negation and quotation attribution. A span hash authenticates words; it does not prove their meaning or the described event. Assistant repetition, a changed annotation or a passed structural check never becomes a host receipt.

For candidate reasoning, each exclusion carries the candidate/evidence domains, a source-bound incompatibility rule and any required directed bridge. The bridge must match the scope and candidate. Missing, unrelated, reversed, inferred or contradictory support leaves the candidate unresolved. Same-domain evidence still needs a rule; negative evidence in one domain does not automatically eliminate an explanation in another. Conditional support retains its conditional status.

Closure distinguishes `OPEN`, `PARTIALLY_CONSTRAINED`, `LOCALLY_CLOSED` and `EXPLICITLY_EXHAUSTED`. A finite source boundary, bounded generator description or completeness proof must be source-bound to the declared scope/member set. Every member must be independently assessed and the unresolved remainder empty. A local finite remainder is explicitly conditional on the described premises; it does not establish world exhaustiveness. The legacy arithmetic API remains available for old callers, with an explicit marker that it cannot certify the new grounded closure contract.

Responsibility is evaluated for an exact actor/task/scope tuple, separately for ownership and execution. The states are `EXPLICITLY_ASSIGNED`, `EXPLICITLY_COMPLETED`, `PLANNED`, `PROPOSED`, `INFERRED` and `UNKNOWN`. Plans do not establish completion; suggestions and adjacent tasks do not establish assignments. Execution does not prove ownership, and ownership does not prove execution. Quoted assignments retain their reported speaker scope; ambiguous speakers cannot inherit the current user's identity. A narrow host text-submission receipt cannot establish external implementation work.

The production context path always includes a source-indexed grounding contract, even without lexical cues. Its sparse and full forms retain the same schemas and provenance fields. Typed authored descriptions use the same validators and can be projected without losing their bindings. Ordinary live text remains explicitly unparsed; null does not mean an empty universe or missing source. The model is instructed to preserve inferred, conditional and reported status in ordinary answers, finished copy and later summaries. No semantic parser, phrase blacklist, output rewrite or additional model request is introduced.

The existing prompt budget exposed a real integration regression. The repaired composition factors repeated generic rules into the mandatory grounding message and selects a compact common expression policy only alongside that message. Standalone `build_system` behavior remains compatible. Frozen mode policy, ontology, personality tendencies, limits and realizations are unchanged. Original dialogue, evidence text, sparse-index boundaries and prompt limits are preserved; both existing six-turn capacity counterexamples pass. The nonempty-visible-answer and unknown-does-not-mean-absent compatibility requirements retain their original wording.

Twenty-six named synthetic, non-heldout fixtures cover twelve candidate cases and fourteen responsibility cases. Fifty-six new checks include adversarial bridges, unknown scopes, task adjacency, actor separation, quoted attribution, conflicting phases, scoped host receipts, immutable inputs, legacy compatibility, sparse/full projection, prompt budgeting, admission refusal and the actual Responses payload/journal path with an injected local transport. The full component suite retains all prior modules/tests. Fixed legacy regression keeps its historical denominator and its expected source-identity sentinel.

The completed-without-visible-output investigation is separate. The preserved raw stream contains a completed terminal and reasoning only; no assistant message or visible text was lost locally. The unchanged parser reproduces the original normalized capture exactly. Provider, transport, parser, retry and generation configuration source remain unchanged. The upstream reason for that provider behavior remains unresolved.

The resulting freeze is engineering evidence for a future fresh validation. It is not target-model semantic acceptance, does not close historical findings, and does not authorize resuming a quarantined revision. No model generation or paid retry occurs in this repair. A future fresh revision must start with zero captures and zero judgments; downstream gates remain locked until its own complete validation passes.
