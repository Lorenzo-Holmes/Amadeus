# Authority Ladder

Governance views: CONVERSATIONAL, INFERRED, SUPPORTED, CANDIDATE, ADMITTED, DURABLE. They are not a monotone automatic upgrade chain and do not require a new code enum. Display eligibility is orthogonal to them.

## Orthogonal axes and actual representations

| Existing axis / object | Exact current representation | Constraint |
|---|---|---|
| Epistemic | UNKNOWN / POSSIBLE / SUPPORTED / CERTAIN | Semantic strength does not issue host permission or ADMIT. CERTAIN remains bounded by evidence. |
| Disposition | UNASSESSED / LOCALLY_CONSTRAINED / EXCLUDED | Exclusion is domain/scope-specific, never an automatic closed universe. |
| Coverage | OPEN / FINITE / EXHAUSTIVE | Finite does not mean exhaustive; a selected exhaustive claim needs its closure basis. |
| Modality | ASSERTED / CONDITIONAL / REPORTED / HYPOTHETICAL | REPORTED certifies a report, not the reported event; conditions survive retrieval. |
| TemporalState | UNSPECIFIED / PLANNED / ASSIGNED / COMPLETED | Labels do not prove a transition or execution receipt. |
| Attribution | Validated strings EXPLICITLY_ASSIGNED / EXPLICITLY_COMPLETED / PLANNED / PROPOSED / INFERRED / UNKNOWN | No actual Attribution enum is assumed. Actor, task, scope and source must match; supplied source text is not itself an independently verified action. |
| EventCandidate | event_candidates record produced by AdmissionController.propose | A candidate may be persisted while remaining untrusted. |
| AdmissionDecision | Host-sealed dataclass and admission_decisions row | ADMIT for a specific allowed payload is distinct from bounded semantic inventory admission. |
| RuntimeCommit | RuntimeStore.commit and persisted event/state transaction plus receipt | No class named RuntimeCommit is required or claimed to exist. |

A DURABLE UTTERANCE_OBSERVED event can contain CONVERSATIONAL text. Only the outer speech occurrence is durable evidence; embedded propositions keep their original modality and authority. Likewise an admitted report, suggestion, planned action or pending candidate does not become true/completed/assigned by storage. Repetition and summary never authorize upgrades.
