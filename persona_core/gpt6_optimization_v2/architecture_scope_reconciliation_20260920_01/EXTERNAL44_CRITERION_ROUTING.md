# External44 Criterion Applicability — 44 / 176

This is a pre-implementation applicability mapping, not answers, scores or a new validation run. The original rubric has exactly four criterion strings in every_turn_review_dimensions, applied to each turn. Those strings are both the original criterion IDs and the only original criterion wording; no paraphrased replacement criterion is invented. Turn IDs follow the existing evaluator normalization: case ID plus _T<number>, and the existing switch tail _S<number>.

Only case IDs/turn counts and the four dimension strings were used to build this mapping. No private_expectations, expected response, per-turn ownership, timestamp solution or chronology is used. The same dimension has the same boundary route for every turn; there is no per-turn production whitelist. Runtime MUST NOT load this file.

Original denominator: 44 turns × 4 criteria = 176, unchanged. Routes: CONVERSATION_UTILITY 44; BOTH 132; STATE_INTEGRITY 0; PROVIDER_TRANSPORT 0; NOT_APPLICABLE_WITH_REASON 0. All 176 remain required. No historical failure is removed or regraded. Transport is separately a prerequisite/stop result; a missing answer stays in the original denominator as unreviewed, never a transport-based exemption.

BOTH records separate A and B judgments for the same original item; the combined item passes only if both pass. Reports must retain 176 unique original pairs and must not misreport the 308 routed subchecks as 308 original criteria. A turn without a requested state effect still needs evidence that unsupported content was not promoted; an authorized utterance observation alone is not pollution. Missing state traces mean B is UNREVIEWED/UNCLEAR, not PASS or N/A.
